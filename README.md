# ÉLITE SEARCH

Элитный PHP-сайт с красивым поиском по коллекции премиальных объектов.

## Возможности

- Поиск по названию, описанию, тегам и категориям
- Фильтры по категориям: Часы, Автомобили, Вино, Отели, Мода, Авиация
- Роскошный тёмный дизайн с золотыми акцентами
- Адаптивная вёрстка
- Чистый PHP без фреймворков и БД (данные в JSON)

## Запуск

```bash
cd elite-search
php -S localhost:8000
```

Откройте http://localhost:8000

## Структура

```
elite-search/
├── index.php          # Главная страница + логика поиска
├── data/
│   └── items.json     # Данные коллекции (25 объектов)
├── assets/
│   └── css/
│       └── style.css  # Стили
└── README.md
```

## Кастомизация

Добавляйте объекты в `data/items.json`.  
Формат записи:

```json
{
  "id": 26,
  "title": "Название",
  "category": "Часы",
  "description": "Описание...",
  "tags": ["tag1", "tag2"],
  "year": 2024,
  "price": "от $10 000",
  "highlight": "Короткая фраза"
}
```

Дизайн можно менять через CSS-переменные в `:root`.
